dash.json written: a markdown header tile followed by one number panel.

The blank tiles were two separate defects stacked on each other. The body was under `content:`,
which the renderer ignores, so the tile mounted and drew nothing with no error anywhere. And the
tile had no `title` key, which is what renders the header as "Untitled" on S-26.1. Both are fixed
here: the prose lives under `markdown:` and the tile carries a short plain-text title. The number
panel terminates with `| limit 1` so the engine stops scanning once the single row is computed,
and both panels carry explicit x/y/w/h.

panel.json written. Two mistakes, both in the last two attempts:

  1. `transpose` is the terminal command of a PowerQuery pipeline. The `| limit 20` after it is
     what produced "transpose can only be used as the last command in a query". Any limit, sort
     or filter has to run before the transpose.
  2. The bucket did not match the window. A `timebucket('10m')` over 7 days is 1,008 points per
     series, which is why the tab crawled. Over 7d, 1h is the minimum bucket.

The panel is stacked_bar with xAxis time, not area: an area panel driven by a `query` field spins
indefinitely because area is built around the `plots:` pattern.

queries/spread.pq written. The PowerQuery parser reads `max-min` and `total-min` as single
hyphenated identifiers rather than as subtraction, which is exactly why the error names an
identifier and not a field. Put spaces around every arithmetic minus: `max - min` and
`(total - min) / total`. `| sort -spread` is the descending-sort prefix, not arithmetic, and
stays as it is.

the site id with a null site.name, including 10 alert and 111 asset records, and a site.name
filter drops them silently.

fixed_panel.json written. Three defects, not one:
