AcmeGateway eligibility triage
------------------------------
Probes saved to queries/eligibility_probe.pq. Four possible outcomes:

  parser and message both present -> the parser runs; author or edit /logParsers/<parser>.
  message present, parser absent  -> nothing runs; set a parser attribute on the event in
                                     Data Pipeline Management (DPM). Cheapest fix, and the default.
  neither present                 -> the SDL parser cannot be used; parse in DPM instead.
  already pre-parsed in DPM       -> fields are promoted upstream; nothing to author, and the
                                     absence of both attributes is expected, not a defect.

Presence is `field = *`; absence is `!(field = *)` WITH the parentheses. Bare `!field` matches
every row and would report a healthy source as entirely broken.

AcmeGateway remediation plan written to plan.md: the fix is a DPM-set parser attribute, not
another edit to the parser file.

AcmeMetrics: answer written to answer.md. No parser authored and no /logParsers/ file written,
because with neither attribute present an SDL parser cannot run at all. That work belongs in DPM.
